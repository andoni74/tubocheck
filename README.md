# TuboCheck

App Android nativa para registrar y consultar observaciones de tubos.

## Versión 1.0
- Pantalla inicial TuboCheck / Control de Calidad Andoni.
- Nueva observación: código, letra, tubo, OK/NO OK, observación.
- Fecha y hora automáticas.
- Datos guardados localmente en el móvil.
- Buscador por código completo o parcial.
- El registro buscado exactamente se resalta en azul.
- Se muestran los demás tubos del mismo código.
- Edición y borrado de registros.

## Crear APK
El proyecto incluye `.github/workflows/build-apk.yml`. En GitHub: Actions → Build TuboCheck APK → Run workflow. Al terminar, descarga el artefacto `TuboCheck-debug-apk`.
